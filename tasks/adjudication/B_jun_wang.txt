DECISION RULES USED (from src/littasks.py docstring + guide Sec. 6.3)
KEEP  slot has >=2 admissible readings, each grounded in stated text/figure evidence, representable on
      the structured grid, scale-relevant (changes the design set or compliance ordering).
CHANGE slot is real; value set is wrong/narrow - replacement values written inline.
DROP  paper states the value (no ambiguity), reading is a mechanism, or it is a reconstruction choice.
Mandatory slots (load sign, unstated volume fraction) are always KEEP with one representative value.
Unstated filter/penalty/Emin/Poisson = solver setting fixed in `recon`, never a slot; CONFLICTING
stated values ARE a slot. Codex non-scale items => DEFER (to recon) / REBUT (evidence wrong).
Add-slot rule: added slots multiply readings; cap each task at 18 readings (L22 precedent), rank adds
by E03 consequence class, and re-run experiments/a06_agreement.py after any change.

CODEX GLOBAL RULING: 51 of 53 non-scale items are material (Poisson ratio, plane stress/strain, Emin).
All DEFER to recon; publish a fixed-constants table once in Sec. 5 (nu=0.3, plane stress, Emin/E0=1e-9,
raised-cosine patches with exact resultants, volume-preserving threshold). Do NOT open slots for them.
